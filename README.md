# Clone Tabnews

Implementação de ponta a ponta do <https://tabnews.com.br> durante estudos do treinamento <https://curso.dev> do **[Filipe Deschamps]**. O **clone-tabnews** é um repositório usado para aprender, a desenvolver, com um projeto que possui situações, problemas e soluções reais.

## 💻 Tecnologias

A stack de desenvolvimento, do tabnews, usa tecnologias amplamente adotadas dentro do ecossistema `Javascript`, facilitando a integração e o deploy contínuo (CI/CD), e o desenvolvimento full-stack (desde a infraestrutura até a interface com o usuário).

- **[Node.js]**: Ambiente de execução para o backend Javascript.
- **[Next.js]**: Framework para desenvolvimento de aplicações web full-stack com `React`.
- **[React]**: Biblioteca JavaScript para construção de interfaces de usuário.

Enxergando a aplicação como uma casa 🏡. O `Node.js` é a fundação que sustenta tudo, o `Next.js` cuida das paredes, dos cômodos e do encanamento, enquanto o `React` entra com os móveis, a decoração e tudo aquilo com que os moradores podem interagir.
